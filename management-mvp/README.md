# Diva Studio Management MVP
Separate application source; do not publish beneficiary data or secrets. Configure server-only DATABASE_URL in Vercel. Requires the dedicated Neon schema, pgcrypto extension and bcrypt password hashes, plus an initial owner account provisioned securely by the database administrator. No public registration. Deploy this directory as an independent Vercel project. This is an MVP: historical migration, account editing, audit review, advanced reports, verified income approval integration, full UI testing and production hardening are outstanding. Never point this preview at existing production data before security testing.
